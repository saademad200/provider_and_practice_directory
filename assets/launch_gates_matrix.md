# Launch Gates Matrix

| Field or action | Shadow mode | Auto update after pilot | Human review required | Reason |
|---|---:|---:|---:|---|
| Phone | Yes | Yes, narrow gate | When conflict or stale evidence exists | Operational field with lower identity risk |
| Website | Yes | Yes, narrow gate | When domain conflict exists | Low risk if canonical domain is corroborated |
| Specialty display normalization | Yes | Limited | When taxonomy implies scope or sources conflict | Taxonomy is a display aid, not licensure proof |
| Address | Yes | No at launch | Yes | Movement, suite, and practice affiliation risk |
| Practice affiliation | Yes | No | Yes | Can affect patient routing and provider identity |
| NPI | Yes | Never | Yes | Identity key, check digit only validates format |
| License status | Yes | Never | Yes | Requires state board review |
| Inactive or retired status | Yes | Never | Yes | False suppression is high harm |
| Duplicate merge | Yes | Never | Yes | Merge errors are hard to unwind |
| Provider movement | Yes | Never | Yes | Needs affiliation and location review |
